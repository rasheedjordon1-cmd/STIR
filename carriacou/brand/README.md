# Carriacou Logistics logo files

| File | Use it for |
|---|---|
| `carriacou-logo-navy` | The full lockup on light backgrounds. Squarespace site logo, documents, email signatures. |
| `carriacou-logo-white` | The full lockup on dark or photo backgrounds. |
| `carriacou-wordmark-navy` / `-white` | The word alone, where the lockup would be too small to read LOGISTICS (under about 120px wide). |
| `carriacou-icon-navy` / `-white` | Square spaces: social avatars and app icons. For the browser tab, use `../favicon-512.png`. |

Each comes as SVG (sharp at any size; use it wherever it is accepted) and as a transparent PNG (logo and wordmark 2400px wide, icon 1024px square).

Colours: navy `#0B1F2A`, white `#FFFFFF`, dock-tab amber `#E8A00D`.

These are a typeset reconstruction of the supplied mark, not the master artwork. Replace them with the vector master when it arrives, and do not send this version to print.
